完整构建指南 ↗

日常命令

same new
生成默认配置与 ignore，不覆盖已有文件。
same scan -r --summary
递归扫描并查看结果、设备决策及学习统计；省略 -r 不进入子目录。
same train ../photos ../archive --summary
在多个目录选择训练文件，分别测量 CPU、CUDA 与 iGPU；结果写入当前工作区的在线模型。需要三个设备后端均可用。
same merge ../other --summary
将其他工作区的模型贡献、缓存和遥测合并到当前工作区，保留本地配置。
same scan --no-telemetry
关闭遥测日志，仍保留在线学习；--no-pgo 才关闭学习及模型读写。
same clean [-r]
删除 .same 状态，包括配置、ignore、摘要缓存、模型和遥测；请先备份。

查看完整 v0.6.0 发布说明 ↗
了解合并语义与边界 ↗

  • 训练即使用：same train <dirs> --summary 以统一预算选取多目录语料；成功样本直接更新普通自动扫描所加载的模型，不另存训练专用模型。
  • 观测完整且易读：训练记录阶段与各后端尝试；--summary 分区展示样本、耗时、模型和遥测，交互终端自动配色，机器重定向保持可解析。
  • 跨工作区合并：same merge [dir] -r --summary 导入模型来源贡献、绝对路径缓存、遥测与缺失的 ignore 规则；保留目标配置。
  • 重复同步不重复学习：来源再训练后重新合并，会替换其较旧模型贡献；扫描结果仍仅包含当前扫描范围，并继续逐字节确认重复。
  • 谨慎移动与发布：--move 只在导入成功并核对来源未变化后删除源 .same；五类发行包仍须经跨平台 Actions 构建、测试和解包验证。
缓存依赖文件元数据，并非文件系统快照。需要完整重算时使用 --rehash；可靠审计请扫描静止目录。性能随硬件、文件分布与磁盘缓存变化；GPU 初始化仍可能拖慢短批次。异步遥测仍占用资源，退出时需等待写入，不承诺零开销。
