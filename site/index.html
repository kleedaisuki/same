构建与安装

需要 CMake 3.25+ 和 C++23 编译器。CUDA 可选；没有 GPU 也能工作。进入需要检查的目录后运行程序。

git clone https://github.com/kleedaisuki/same.git
cd same
cmake -DSAME_CUDA_MODE=off -P tools/build.cmake

日常命令

same new
生成完整默认配置和推荐 ignore，不覆盖已有文件。
same scan -r
递归扫描；省略 -r 只扫描当前目录。
same --summary
显示统一 Summary 表，含结果、数据库及性能统计。
same clean [-r]
删除 .same 状态；-r 扩展到子目录。包含配置和 ignore，请先备份。
