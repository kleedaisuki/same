选择发布包

下载 GitHub Release ↗

  • Windows x64 / Linux x64：standard 包含 CPU 与可选 iGPU；cuda 包额外包含 CUDA 后端。
  • macOS Apple Silicon：standard 包，CPU 与可选 iGPU；不支持 CUDA。
  • CUDA 包需要兼容的 NVIDIA 驱动，不需要自行安装编译器。设备不可用时保留 CPU 路径。

每个包均由 Actions 构建、测试并验证解包后的程序，附 SHA-256 校验、来源证明与准确构建信息。Linux 基线为 Ubuntu 24.04；macOS 为 14+ ARM64，尚未公证。

完整构建指南 ↗

日常命令

same new
生成默认配置与 ignore，不覆盖已有文件。
same scan -r --summary
递归扫描并查看结果、设备决策及学习统计；省略 -r 不进入子目录。
same scan --cpu
明确使用 CPU；--cuda 和 --igpu 可用于设备对照。
same scan --no-telemetry
关闭遥测日志，仍保留在线学习；--no-pgo 才关闭学习及模型读写。
same clean [-r]
删除 .same 状态，包括配置、ignore、摘要缓存、模型和遥测；请先备份。

RELEASE NOTES / 0.5.0

学会选择，也学会不启动。

从真实任务学习三种后端的成本，跨运行复用经验；没有足够收益时，安心使用 CPU。

在线模型与调度设计 ↗
真实性能与局限 ↗

  • 三后端，统一决策：CPU SIMD、CUDA 独显与 OpenCL 核显；固定四维成本模型考虑数据量、实际批容量及竞争，不把“GPU”当作自动更快。
  • 经验留到下一次：.same/model.db 保存设备匹配的学习参数和启动历史；线程本地更新，收尾合并，避免重复累计。
  • 先算启动账：设备发现和初始化也有成本。短任务默认保持保守，核显忙时不等待；可恢复设备错误完整回退 CPU。
  • 可查、可关：--summary 展示本轮统计；.same/telemetry.db 独立保存本地诊断，不上传文件内容。
  • 真正的发布链路：跨平台验证、CUDA 必需编译、发布包烟雾测试与标签发布串联。托管 CI 验证构建和无 GPU 回退；真实设备执行单独实测。
缓存依赖文件元数据，并非文件系统快照。需要完整重算时使用 --rehash；可靠审计请扫描静止目录。性能随硬件、文件分布与磁盘缓存变化；GPU 初始化仍可能拖慢短批次。异步遥测仍占用资源，退出时需等待写入，不承诺零开销。
