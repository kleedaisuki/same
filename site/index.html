选择发布包

下载 GitHub Release ↗

  • Windows x64 / Linux x64：standard 包含 CPU 与可选 iGPU；cuda 包额外包含 CUDA 后端。
  • macOS Apple Silicon：standard 包，CPU 与可选 iGPU；不支持 CUDA。
  • CUDA 包需要兼容的 NVIDIA 驱动，不需要自行安装编译器。设备不可用时保留 CPU 路径。

每个包均由 Actions 构建、测试并验证解包后的程序，附 SHA-256 校验、来源证明与准确构建信息。Linux 基线为 Ubuntu 24.04；macOS 为 14+ ARM64，尚未公证。

完整构建指南 ↗

日常命令

same new
生成默认配置与 ignore，不覆盖已有文件。
same scan -r --summary
递归扫描并查看结果、设备决策及学习统计；省略 -r 不进入子目录。
same scan --cpu
明确使用 CPU；--cuda 和 --igpu 可用于设备对照。
same scan --no-telemetry
关闭遥测日志，仍保留在线学习；--no-pgo 才关闭学习及模型读写。
same clean [-r]
删除 .same 状态，包括配置、ignore、摘要缓存、模型和遥测；请先备份。

汇总布局与颜色语义 ↗
构建与 CUDA 工具链 ↗

  • 八个分区，完整证据：结果、存储、性能、路由、在线模型、工作线程、模型持久化与遥测依次展开，不省略原有统计。
  • 颜色只做加速：成功、警告、错误、计时和模型证据具有语义高亮；关闭颜色后，标签与状态词仍表达全部含义。
  • 机器接口不动：TSV、原始 key=value、stdout/stderr、退出码及 NO_COLOR 契约保持兼容。
  • CUDA 选择有证据：Windows 从新到旧探测 VS x64 环境，只有能与所选 nvcc 完成 C++20 编译链接的实例才会被采用。
  • 严格发布门：五类跨平台包分别构建、测试、解包烟雾验证并生成校验和；标签与版本不一致时拒绝发布。
