# same v0.5.0

## 下载 / Downloads

- Windows x64 / Linux x64: `standard` includes CPU + optional OpenCL iGPU; `cuda` additionally includes CUDA.
- macOS Apple Silicon: `standard` includes CPU + optional OpenCL iGPU. There is no CUDA support on macOS.
- CUDA packages require a compatible NVIDIA driver, not a locally installed CUDA compiler. Standard packages need no CUDA runtime.
- Windows packages target Windows 10/11 x64. Linux packages are built on Ubuntu 24.04 (glibc 2.39+). macOS packages target macOS 14+ ARM64.
- Verify `SHA256SUMS` and build provenance before use. Archives include licenses and `build-info.json` with the exact source commit.

## 更新 / Changes

- Native BLAKE3 iGPU support with optional dynamic OpenCL loading and exact CPU differential validation.
- CPU/CUDA/iGPU contextual cost prediction, thread-local profiling and cross-run learning in `.same/model.db`.
- Budgeted cold discovery/activation; no promise that GPU execution is always faster.
- Independent telemetry, safe CPU fallback and unchanged final byte-for-byte verification.
- Cross-platform CI now tests the actual Release package build, including required CUDA compilation on Windows and Linux.

Hosted CI has no NVIDIA GPU: it validates CUDA compilation, packaging and graceful fallback. Real CUDA and Intel Iris Xe execution were separately tested locally. macOS archives are not Apple-notarized; use only artifacts whose origin you have verified.
